# EsTerra Craft — craft.dwatamon.com

Static site (no build). Hosted on GitHub Pages; custom domain in `CNAME`.

- `index.html`, `shop.html`, `custom.html`, `artist.html`
- `js/config.js` — WhatsApp number, Paystack public key, deposit amount
- `js/products.js` — the catalogue (edit/add products here)
- `images/products/` — product photos (filename goes in `image:` in products.js)
- `images/artist/artist.jpg` — artist portrait
- `images/gallery/` — home page lookbook photos
- `images/uploads/` — drop folder for new files

Orders: cart -> pre-filled WhatsApp message. Custom: form -> Paystack (GHS 150) -> pre-filled WhatsApp message.
